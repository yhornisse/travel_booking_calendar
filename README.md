# Travel Booking to Calendar

ブラウザで開いている旅行予約ページから情報を抽出し、Googleカレンダー登録用のページをワンクリックで開くChrome拡張機能です。

## 特長

- 予約情報を自動抽出してGoogleカレンダーに登録
- 文字化けや冗長情報を抑えた安全なURL生成
- Trip.com / Booking.comに対応

## 対応サイト

- Trip.com
  - 航空券
  - 宿泊
  - 空港送迎
- Booking.com
  - ホテル予約（確認ページ）

## 使い方

1. Chromeの拡張機能として読み込み
2. 対応サイトの予約ページを開く
3. 拡張機能のボタンを押す
4. Googleカレンダーの登録画面が新規タブで開く

## インストール（開発用）

1. Chromeで `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このリポジトリのフォルダを選択

## 生成される内容

- タイトル: `【カテゴリ】タイトル`
- 日時: 予約ページのチェックイン/アウトや出発/到着時刻
- 場所: 住所や空港名など
- 詳細: 予約番号・概要（冗長情報は除外）

## 権限

- `activeTab`: 現在開いているタブから情報を抽出
- `scripting`: ページ上で抽出処理を実行

## 注意事項

- 予約ページの表示形式が変わると抽出に失敗することがあります。
- 登録内容は必ず最終確認してください。
